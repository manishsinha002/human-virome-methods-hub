# Suggest a tool

Know a computational method or tool that should be considered for the Human Virome Methods Hub? Submit a proposal with evidence so maintainers can assess its fit.

[Open the tool proposal form](https://github.com/manishsinha002/human-virome-methods-hub/issues/new?template=add-method.yml)

Please include relevant references (such as a DOI or PMID), the human-virome use case, specimen type, and known limitations. Disclose any conflicts of interest.

Submitting a proposal does not add it to the site automatically. Maintainers review proposals, and accepted changes are added through a reviewed pull request. See [Contributing](contribute.md) for the full process.
