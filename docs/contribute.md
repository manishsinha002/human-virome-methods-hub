# Contribute

Use GitHub Issues for corrections and proposals. Use pull requests for evidence-backed changes to structured data or guidance.

## Suggest a tool

[Submit a tool proposal](https://github.com/manishsinha002/human-virome-methods-hub/issues/new?template=add-method.yml) using the GitHub issue form. You may need a GitHub account to submit it.

Maintainers review proposals and their supporting evidence. A suggestion does not update the website automatically: accepted changes are made to the repository through a reviewed pull request, which must pass schema validation. Merging to `main` triggers the website build and deployment.

GitHub sends issue notifications according to each maintainer's repository notification settings.
