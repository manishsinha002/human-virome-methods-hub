# Human Virome Methods Hub

A living, evidence-linked guide to method selection and reporting in human viral metagenomics.

## What makes this resource different?

Rather than cataloguing every available virome tool, this hub asks:

- Which viral fraction does a method recover?
- Which human specimen types has it been evaluated on?
- What claims can its output support?
- What are its known failure modes?
- Which independent benchmarks exist?

## Evidence pathway

**Sequence detection → genome reconstruction → persistence → activity → host linkage → biological function**

!!! warning "Prototype status"
    This community prototype accompanies an HVP Working Group review. Recommendations are not official HVP standards until formally reviewed and endorsed.
